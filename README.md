# Prefix D

ブラウザ向け3Dドライビングゲーム「Prefix D」（個人開発）。
自分で運転して街を走るほか、タイムアタック・NPC対戦・オンラインで友だちと走れる。

- 遊ぶ: https://shuheikomatsuki.github.io/prefix-d/
- 設計提案: [docs/design-proposal.md](docs/design-proposal.md)

## 遊び方

### 画面の流れ

起動するとタイトル画面から始まる。どれかのキーを押す（スマホはタップ）とトップメニューになり、プレイモード（自由に走る・タイムアタック・NPCと対戦・ライバルとバトル）を選んで、コース・対戦相手・ルール・自分の車・時間帯と天気を1画面ずつ選び、最後に「スタート」。左に一覧、右に選んでいるものの詳しい説明が出る（コースは上から見た形・高低差のグラフ・全長・最大勾配・道幅・おすすめの車、車は回る車の見た目と性能、ライバルは写真・強さ・マシン）。走っている間は `Esc`（スマホは ☰）でポーズ画面を開き、トップメニューへ戻れる。`?map=3` のようにマップを指定して開いたときは、タイトルを飛ばしてすぐ走れる。

### 運転

| キー | ゲームパッド | 操作 |
|---|---|---|
| `W` / `↑` | RT（または A） | アクセル |
| `S` / `↓` / `Space` | LT | ブレーキ（停止中に押し続けると後退） |
| `A` `D` / `←` `→` | 左スティック | ハンドル |

### タイムアタック

`T`（またはトップメニューの「タイムアタック」）で、スタートラインの手前に並ぶ。アクセルを踏むとカウントダウンが始まり、タイムを計る（自分のタイミングでスタートできる）。レース用のマップにいればそのコース、それ以外ならサーキットへ移動する。走っている間は `N` でコースを替えられる。

| コース | 内容 |
|---|---|
| サーキット | 1周 約3.5km の周回コース。1km のメインストレートの先の低速ヘアピン、高速の S 字、バックストレート、複合コーナー、半径 200m の高速コーナー。道路の外に退避帯（芝生）と壁があり、カーブには縁石。3周 |
| 首都高（湾岸線・ループ） | オリジナルの首都高（一周 約5.9km）。高架の3車線で両側は壁。カーブはなめらかな円で、立体交差がある。1.3km のロングストレート（湾岸線）の先で、左に 540° 回りながら上る二重のループ（下の輪の真上を上の輪が通る）、海を渡るレインボーブリッジのような吊り橋、都心環状線のような曲がりくねった区間、405° 回って自分の上を越えていくループ、215° 曲がり続ける大きなカーブを通ってロングストレートに戻る。1周 |
| テクニカルサーキット | 低速コーナーが続く周回コース（約2.4km）。クランク、ヘアピン、2つのシケイン、180° 回り込むコーナー。2周 |
| 峠（ヒルクライム） | ふもとから頂上まで 150m 上る一本道（約2km）。半径 150m の高速コーナー、S 字、3つのヘアピンが混じる。坂で加速が鈍る |
| 峠（ダウンヒル） | 同じ峠を頂上から下る。スピードが乗るので早めのブレーキが大事 |
| 峠（山越え） | 100m あまり上って峠を越え、反対側へ下る（約2.1km）。頂上は見通しのよい高速の左右 |
| 峠（Uターン） | 谷沿いに上り、頂上のヘアピンで折り返して 38m 横を並んで下る（約2.2km）。行きの高速コーナーは帰りの低速コーナーになる。ゴールはスタートのそば |
| つづら折り（ヘアピン） | 斜面をつづら折りで 160m 上る。180° のヘアピンが 12 個続く（約2.1km） |
| つづら折り（ダウンヒル） | つづら折りを上から下る。ヘアピンの内側を突っ切って、段差から下の道路へ飛び降りる近道（下記）がある |
| 激坂（ヒルクライム） | 約1.4km で 230m 上る急坂（平均 17%）。きついヘアピンが 3 つ。パワーのない車は伸びなくなる |
| 激坂（ダウンヒル） | 同じ激坂を下る。ブレーキが遅れるとコーナーで止まりきれない |
| 峠（ロング） | 上りと下りを何度もくり返す約2.9kmの長いコース。高速コーナーとヘアピンが交互に来る |
| 峠（超ロング） | 上りと下りをくり返す約6.2kmのいちばん長いコース |
| ロングストレート（ヒルクライム / ダウンヒル） | 峠の途中に、まっすぐな 800m のロングストレートと、ごく僅かに左右へくねる 650m のロングストレートがある。前後と間はふつうの峠のコーナー（約2.9km、高低差 170m） |
| 橋とトンネルの峠（ヒルクライム / ダウンヒル） | 約4.8km の峠。コーナーの続く区間の途中で 3 回谷を橋で渡り、短いトンネル（90m）と長いトンネル（360m）を抜ける（高低差 230m） |
| 八方ヶ原風の峠（往復） | 4つのセクションに分かれた峠（道路 3.5km）を往復する（約6.8km）。第1は道幅が狭く木が茂って見通しの悪い古い道、第2は拡幅済みのきれいな広い道だが路面が荒れていて車が跳ねる。ハイポイントコーナーの先の第3はきついダウンヒルで、高さ 55m の谷に架かる大きな橋を渡ると、第4はきついヒルクライム（道幅 10m で、追い抜きやすい）。330° 回り込むループ橋、カーブの途中の 240m のトンネルを抜け、上り切った先の平らな道を少し走って頂上の広場で U ターンし、同じ道を戻ってきてスタートラインがゴール |

- 走っている間は、これまでの周回タイム（自己ベストの同じ周との差）と、コース全体の地図（自分は赤、ゴーストは水色）を出す。
- 峠の高低差は見た目と坂の重力だけで、衝突の計算は平らなまま（`src/map/terrain.ts`）。
- 道路の外を走ると遅くなる。サーキットとテクニカルサーキットでは、道路の外は退避帯の草地で、グリップが落ちて速度も出なくなる（普通車で 40km/h くらいまで）。
- つづら折り（ダウンヒル）では、ヘアピンの内側（行きと帰りの道路にはさまれた所）がコンクリートの面になっている（いろは坂の「インベタのさらにインベタ」）。コーナーの手前で内側へ飛び込めば、道路よりずっと小さく回れる。面は上の道路の高さから下っていき、下の道路の縁で段差（最大 2.5m）になって終わるので、段差から飛び降りると真下が下の道路。面の上は落ちず、コースアウトにもならない（周回も進む）。浮いている間はハンドルもアクセルも効かないので、向きを決めてから飛ぶ。面の外側は崖（`src/map/roadShortcuts.ts`。180° の円弧の前後が直線のヘアピンを探して帯を作る）。
- 峠では、道路の外は少しの路肩の先が崖（岩肌の色の斜面）になっている。路肩より外へ出ると「コースアウト！」と出て落ち、1 秒ほどで落ちた地点の少し手前に止まった状態で戻される（その間もタイムは進む）。カーブの外側にはガードレールがある。NPC も同じ。
- 峠の橋は深い谷（底に川）に架かり、トンネルは山の中を抜ける。橋の上とトンネルの中は両側が壁で、落ちることはない。地図の記号は `=`（橋）・`~`（川）・`#`（トンネル）。
- 練習用の小さな街と教習所コースを除くすべてのコースは、タイルではなく直線と円弧をつないだ中心線で道路を描く（`src/map/road.ts`）。タイルのコースのように「90° 曲がって直線」をくり返すのではなく、半径（大きいほど速く回れる）と曲がる角度を区間ごとに決めるので、半径 200m の高速コーナーから半径 16m のヘアピンまで、なめらかな円のカーブになる。周回のコースは最後の直線・円弧・直線を計算して始まりにつなぎ（`closeLoop`）、ダウンヒルは上りの道路を逆向きにたどる（`reverseRoad`）。峠（Uターン）の帰り道は、行きの道を横へずらした道を逆向きにたどる（`alongside`。内側になるカーブは半径が小さくなる）。区間ごとに高さ・道幅・橋・トンネル・荒れた路面を指定でき、道路が自分の上を越える立体交差も作れる。衝突の計算は平らなままなので、立体交差では上の道路と下の道路の壁を別の層に分け、車はいま走っている道の層の壁と車にだけぶつかる。どちらの道にいるかは、直前にいたコース上の位置から近くだけを探して追う（`src/race/roadCourse.ts`）。往復のコースでも、行きと帰りを向きで見分ける。
- 荒れた路面は細かく波打っていて、110km/h くらいまでは揺すられるだけだが、それより速いと波の頂上で少し跳ねる（浮いている間はタイヤが効かない）。

- コースのタイル（中心線で描く道路では 10m ごとの区間）を順にたどった場合だけ周回に数える。コースを外れて先へ近道すると「コースに戻ってください」と出て、戻るまで周回が進まない。逆向きに走ると「逆走しています」と出る。
- 自己ベスト（3 周の合計と最速ラップ）は、コースと車の組み合わせごとにブラウザ内（localStorage）に保存する。
- 自己ベストの走りは、半透明の水色の車（ゴースト）として一緒に走る。
- `R` でスタートからやり直し、もう一度 `T` でやめる。

### ランキング（ゴーストと対戦）

`L`（スマホは ☰ メニューの「ランキング」）で、コースごとのランキング（上位 20 件）を、名前・車・タイム・日付つきで出す。最初は「すべての車」の記録をまとめて出し、車を選ぶとその車だけのランキングになる。オンライン用のサーバーを使う。

- 名前を入れておくと、タイムアタックでゴールしたとき自己ベストが走り（ゴースト）と一緒に自動で送られ、結果に順位が出る。名前を入れる前に出した自己ベストも、ランキングを開いたときに送られる。
- 記録はコースと車の組み合わせごとに、1人につき一番速いものだけが残る（同じブラウザを同じ人とみなす。ブラウザごとに作る秘密の id で見分ける）。「すべての車」では、同じ人でも車が違えば別の行になる。
- 「対戦」を押すと、その人のゴースト（オレンジ色、名前付き）とそのコース・車でタイムアタックする。自分の自己ベストのゴースト（水色）も一緒に走る。
- 友だちと遊ぶ前提なので、偽のタイムを防ぐ仕組みはない。

コースと車は、表示名ではなく変わらない id（`src/map/maps.ts` の `id`、`src/sim/vehicle.ts` の `VEHICLE_PRESETS` の `id`）でランキングを分けている。表示名は自由に変えてよい（例: 「普通車」を具体的な車名にしても、id が `standard` のままならランキングはそのまま）。車の性能を大きく変えるなら、新しい id にすると新しいランキングになる（古いランキングはどこからも開かれなくなるだけで、消さなくても困らない）。

### NPC対戦

`Y`（スマホは ☰ メニューの「NPCと対戦」）で、タイムアタックと同じコースを NPC 3台と走る。NPC が前に並び、自分は最後尾からスタートする。

- NPC の強さは `K`（スマホはメニュー）で 初級／中級／上級／達人／伝説 を選ぶ（`?npc=pro` のように URL でも指定できる）。強いほど理想のライン（レーシングライン）を正確になぞり、カーブとブレーキで車の限界近くまで使う。伝説は車の性能をほぼ使い切る。
- NPC は自分と同じ車種・同じ物理で走る。前の車に追いつくと横に出て抜き、抜けないときは速度を合わせる。ぶつかれば押し合う。
- 走っている間は順位を出し、ゴールすると順位表を出す（まだ走っている NPC がゴールするたびに更新する）。NPC 対戦の結果は自己ベストには残さない。

### 車

| 車 | 最高速 | 特徴 |
|---|---|---|
| 普通車 | 180km/h | 扱いやすいふつうの車 |
| 軽自動車 | 140km/h | 遅いけれど小回りがきく |
| カプチーノ | 170km/h | FR・軽のオープンカー。とても軽く、小さく鋭く曲がる |
| スポーツカー | 250km/h | 速くて曲がる、くせのない車 |
| AE85 | 160km/h | FR・AE86の兄弟車。軽いが非力で、坂と直線は苦手 |
| AE86 | 210km/h | FR・軽い。直線は遅いがコーナーとブレーキが強い |
| シビック (EG6) | 215km/h | FF・軽い。パワーは控えめだが曲がりやすい |
| シビック (EK9) | 225km/h | FF・高回転のVTEC。軽くて立ち上がりが鋭い |
| シルビア (S13) | 220km/h | FR・ターボ。パワーはそこそこで、お尻を流しやすい |
| シルビア (S14) | 235km/h | FR・ターボ。S13よりパワーがあり、少し大きく安定 |
| RX-7 (FD3S) | 260km/h | FR・速いがお尻が流れやすい（横のグリップが弱め） |
| ランエボIII | 240km/h | 4WD・大きなウイング。IVより少し非力 |
| ランエボIV | 245km/h | 4WD・加速とグリップが強い |
| GT-R (R32) | 265km/h | 4WD・最高速が高いが、重くてハンドルの反応が遅め |
| GT-R (R34) | 285km/h | 4WD・最高速がいちばん高い。R32より速く、高速コーナーも安定 |

- 最高速は、イニシャルDのアニメの場面（メーターの読み・直線での伸び・車どうしの差）と、それぞれの車のチューニングから見積もった値。アクセルを踏み続けると、平らな直線でこの速さに落ち着く（エンジンの加速と空気抵抗が釣り合う速さ）。
- 性能として持っているのは、最高速・加速（最高速に近づくほど弱まる）・ブレーキ・アクセルを離したときの減速・空気抵抗・ホイールベース（小回り）・最大舵角・ハンドルを切る速さと戻る速さ・コーナーで出せる横G・横滑りの収まりやすさ（グリップ）。重さや駆動方式（FR・FF・4WD）は、これらの数値の組み合わせで表している（重い車は加速・ブレーキ・ハンドルの反応を控えめにするなど）。坂の重力と草地での減速はどの車にも同じようにかかる。
- 当たり判定の大きさはどの車も同じで、見た目（屋根の高さ・窓の形・リアウイング・色）と性能（`src/sim/vehicle.ts` の `VEHICLE_PRESETS`）が違う。見た目は `src/render/carMesh.ts` の `CAR_STYLES`。
- 一人で走るときは車ごとの色、オンラインの部屋では人ごとに割り当てた色になる。

### ライバルとバトル

`B`（☰ メニューの「ライバルとバトル」）で、名前付きのライバルと 1 対 1 で走る。メニューでは 対戦相手 → ルール → コース（最初はライバルの得意なコース）→ 自分の車 → 時間帯・天気 の順に選ぶ。

ルールは2つ。

- **横に並んでスタート**: 先にゴールしたほうの勝ち
- **先行後追い（サドンデス方式）**: 先行と後追いに分かれ、後追いは先行の 12m 後ろからスタートして1本（周回コースでも1周）走る。判定はゴールの時点でする。後追いが先行を抜いて先にゴールしたら後追いの勝ち、後追いが先行のゴールから 1秒より遅れたら先行の勝ち。1秒以内に続いてゴールすれば引き分けで、先行と後追いを入れ替えて次の1本へ（決着がつくまで続く）。最初に自分が先行か後追いかを選べる。走っている間は何本目か・差を上に出す（`src/race/suddenDeath.ts`）

- 勝った相手にはメニューで WIN の印が付く（ブラウザ内に保存）。ライバルは `src/race/rivals.ts` で追加・変更できる。
- メニューのライバルの写真は、画像を `public/rivals/` に置き、`src/race/rivals.ts` のそのライバルに `photo: 'rivals/takumi.jpg'` のように書くと出る（縦長 3:4 くらいがよい）。書いていないライバルは名前の頭文字の絵になる。
- NPC 対戦とバトルでは、走っている間の順位を名前付きで出し、結果の順位表にも名前を出す（自分はランキング用に入れた名前。未入力なら「あなた」）。

### 時間帯と天気

☰ メニュー（パソコンは Esc）でプレイモードとコースなどを選んだ後の「時間帯・天気」の画面で、朝・昼・夜と普通・雨・霧を選べる（ブラウザ内に保存。`?time=night&weather=rain` のように URL でも指定できる）。

- 朝は空が橙色で日差しが低く、影が長い。夜は暗く、自分の車のヘッドライトが前を照らす。
- 雨は空が暗く雨粒が降り、タイヤのグリップ（横G・横滑りの収まりやすさ）が 78%、ブレーキが 80% になる。NPC やライバルも同じ条件で走る。走っている途中で天気を変えると、レースはスタートからやり直しになる。
- 霧は遠くが白くかすみ、70m ほど先までしか見えない。
- 見た目は `src/render/scene.ts`、雨の性能は `src/game/environment.ts`。

### スマホ・タブレット

タッチ操作の画面が出る（パソコンでも画面に触れるか `?touch` を付けると出る）。

- 左半分を左右になぞる: ハンドル（指を置いた場所が中心）
- ☰ メニューの「ハンドル: 傾ける」にすると、スマホをハンドルのように傾けて曲がる（切り替えた時の持ち方がまっすぐ。左半分をタップすると今の持ち方をまっすぐに合わせ直す。iPhone では動きセンサーの許可を求められる）
- 右下のボタン: アクセル／ブレーキ（止まってから押し続けると後退）
- 上のボタン: カメラ切替・リセット・☰（ポーズ画面）
- 指を離したのにブラウザが知らせてこないことがあるので、指の数が変わるたび・アプリを切り替えたときにペダルを確かめ直し、押しっぱなしにならないようにしている
- ホーム画面に追加すると、アドレスバーなしの全画面で遊べる（iPhone は Safari の共有ボタン →「ホーム画面に追加」。Android はメニューの「全画面で遊ぶ」でも可）。ホーム画面から開いたときは Safari と保存場所が別なので、名前や自己ベストは引き継がれない

URL に `?map=1` を付けると教習所コースから始まる。`?car=sport`（`standard`／`kei`／`sport`）で開始時の車を選べる。`?room=ABCD` は招待リンクで、開くと参加画面が出る。`?debug` を付けると開発者ツールから `window.__game` で状態を触れる。

### オンライン（マルチプレイ）

クライアント権威方式: 各プレイヤーが自分の車を計算して 20 回/秒で位置を送り、サーバー（Cloudflare Workers + Durable Objects）は部屋ごとに中継するだけ。他の人の車は 0.1 秒前の位置を補間して表示し、自分の物理ワールドには動かない車体として置く（ぶつかると自分の車だけが押し返される）。

無料枠を守るための制限:

- 接続できるのはゲームのページ（`https://shuheikomatsuki.github.io`）と手元の `localhost` からだけ。ほかのサイトからの接続は断る。
- 日本国内（Cloudflare が IP から判定）からの接続だけ受け付ける。対象は `server/wrangler.jsonc` の `vars` で変えられる（`"*"` で制限なし）。
- 5 分間車が動いていない人は部屋から外す。つないだまま 15 秒以上参加しない接続も切る。
- タブが裏に回っている間は位置を送らない。
- 最後の 1 人が抜けた部屋は、保存していた値（マップ）を消す。
- ランキングは、コースと車の組み合わせごとに1つの Durable Object（`server/src/leaderboard.ts`）に、上位 50 件とそのゴーストを保存する。読み書きは `GET`/`POST /boards/<コース>/<車>`、ゴーストは `GET /boards/<コース>/<車>/ghosts/<記録の id>`。接続できるページと国の制限は部屋と同じ。

手元で試すとき（`npm run server:dev` は国の制限を外して起動する）:

```sh
npm run server:dev                      # http://127.0.0.1:8787 でサーバーを起動
npm run dev                             # 別のターミナルで
# http://localhost:5173/?server=http://127.0.0.1:8787 を2つのウィンドウで開き、O キーで同じ部屋コードに参加
```

公開の設定（初回のみ）:

1. Cloudflare のダッシュボードで「Workers & Pages」を一度開き、`workers.dev` のサブドメインが作られていることを確認する。
2. 右上のアイコン → My Profile → API Tokens → Create Token → テンプレート「Edit Cloudflare Workers」でトークンを作る。
3. アカウント ID を控える（ダッシュボードのアカウントのホーム、または Workers & Pages の画面の右側に表示）。
4. GitHub のリポジトリ → Settings → Secrets and variables → Actions の **Secrets** に `CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` を登録する。
5. main の CI（Actions → 最新の main の実行 → Re-run all jobs）を実行すると `deploy-server` ジョブがサーバーを公開し、ログに `https://car-game-server.<サブドメイン>.workers.dev` が出る。
6. 同じ画面の **Variables** に `SERVER_URL` としてその URL を登録し、もう一度 CI を実行すると、ゲーム側にサーバーの URL が組み込まれる。

### 構成

| ディレクトリ | 役割 |
|---|---|
| `server/` | マルチプレイの中継サーバー（Cloudflare Workers + Durable Objects） |
| `src/net/` | 通信内容の定義、WebSocket 接続、受信した車の補間 |
| `src/core/` | 固定タイムステップのゲームループ、キーボード・ゲームパッド入力 |
| `src/game/` | マップ1つ分（物理ワールド・車・描画物）の生成と破棄、他のプレイヤーの車 |
| `src/audio/` | Web Audio API で合成する効果音（エンジン・スキール・衝突） |
| `src/sim/` | 車両モデル（`vehicle.ts`、描画非依存）、Rapier 物理ワールド、車 |
| `src/race/` | タイムアタックと NPC: コースの抽出と中心線、周回・近道・逆走の判定、ゴースト、自己ベストの保存、レーシングラインと NPC の運転 |
| `src/map/` | マップ定義（`maps.ts`）。タイルマップの解析（`tilemap.ts`）と、中心線で描く道路（`road.ts`）。障害物配置 |
| `src/render/` | Three.js のシーン、マップ・車・標識のメッシュ、カメラ |
| `src/ui/` | HUD（速度・ギア・操作説明・通知）、メニュー（`menu.ts` 画面の流れ、`menuDetails.ts` 右側の説明、`courseInfo.ts` コースの形と高低差、`carStats.ts` 車の性能の棒） |

- 車の挙動の調整は `src/sim/vehicle.ts` の `DEFAULT_VEHICLE_PARAMS`。
- マップは `src/map/maps.ts` の文字グリッドを書き換えるだけで変更・追加できる（凡例は `src/map/tilemap.ts`）。標識やカーブのガードレールもここで指定する。
- 中心線で描く道路のマップは、`MapDefinition.road` に直線（`straight`）と円弧（`arc`）の区間を並べて書く（`src/map/road.ts` の `RoadPiece`）。周回の道路は始まりに戻るよう長さを合わせる（合わないとエラーになる）。高さの差の足りない交差もエラーになる。

### 公開

`main` ブランチへ push すると GitHub Actions がテスト・ビルドし、GitHub Pages（https://shuheikomatsuki.github.io/prefix-d/ ）に公開する。
ビルドは相対パスなので、リポジトリ名を変えても設定はいらない（URL の最後がリポジトリ名になる）。
初回のみ、リポジトリの Settings → Pages → Source を **GitHub Actions** に設定する。
