# car-game

ブラウザ向け3Dドライビングゲーム（個人開発）。
現在は第3段階：自分で運転するほか、運転が苦手なキャラクター「アッティー」に助手席から声やボタンで指示を出して運転してもらえる。

- 設計提案: [docs/design-proposal.md](docs/design-proposal.md)

## 遊び方

`Q` で「自分で運転」と「アッティーに指示」を切り替える。

### 自分で運転

| キー | ゲームパッド | 操作 |
|---|---|---|
| `W` / `↑` | RT（または A） | アクセル |
| `S` / `↓` / `Space` | LT | ブレーキ（停止中に押し続けると後退） |
| `A` `D` / `←` `→` | 左スティック | ハンドル |

### アッティーに指示（助手席から）

アッティーは左車線を走り、交差点では指示が無ければ直進する。直進できない交差点では、止まらずに左（無ければ右）へ曲がる（「この先まっすぐ行けないから、ひだりに行くね」と言うので、違う方向に行きたければその場で指示する）。右左折・まっすぐの指示は、すでに通り方を決めた交差点でも、速度を落として曲がれる距離があれば反映する。

| キー | 指示 | 声の例 |
|---|---|---|
| `1` | 発進して | 「発進して」「行って」（「発信」と誤認識されても可） |
| `2` | スピード上げて | 「もう少しスピード上げて」「速く」「飛ばして」（巡航 20→30→40→50→60→80→100km/h、最初は 40km/h） |
| `3` | ゆっくり | 「ゆっくり走って」「スピード落として」 |
| `4` | 止まって | 「止まって！」「ストップ」 |
| `5` / `6` | 次を左／右 | 「次の交差点を右に曲がって」「その角を左」。「右」「左に曲がって」だけなら、すぐ先に曲がれる交差点があればそこで、無ければその場で曲がる |
| `T` / `Y` | 今すぐ左／右 | 「今すぐ右」「ここで左」「ハンドル右に切って」（その場で 90° 曲がる。道路から外れてもよい） |
| `7` | まっすぐ | 「まっすぐ」 |
| `8` | 危ない！ | 「危ない！」 |
| `9` / `0` | そこじゃなくて次を左／右 | 「そこじゃなくて、次を左！」 |
| `U` | Uターン | 「Uターンして」「引き返して」（止まれる距離の先の道路でくるっと戻る） |
| `Z` / `X` | 左に寄って／右に寄って | 「右に寄って」「ちょっと左」（曲がらずに走る位置を 1.5m ずつずらす。反対車線まで寄れる） |
| `L` | 車線に戻って | 「車線に戻って」（いつもの左車線の真ん中へ） |
| `B` | 道に戻って | 「道に戻って」「道路に出て」（コースアウト中に、いちばん近い道路へ向かう） |
| `V` | 音声認識の ON/OFF | Chrome / Edge のみ。スピーカーだとアッティーの声を拾うことがあるのでヘッドホン推奨 |
| `K` | 運転のうまさ（ふつう／やさしい／にがて） | |
| `F` | 顔写真 | アッティーの顔に自分の写真を貼る。決定すると写真から顔の形を読み取り（MediaPipe）、鼻や頬の出た立体の顔にする（「立体にする」を外すと写真をそのまま貼る。「顔写真をはずす」で元の顔に戻る）。写真と顔の形はブラウザ内（localStorage）にだけ保存され、送信されない |

「ふつう」「やさしい」は指示どおりに走る（違いは反応の速さとふらつき）。「にがて」は反応が遅く、左右を聞き間違えたり、曲がる方向を間違えたり、急にブレーキを踏んだりする。「止まって」「危ない」だけは必ずすぐ反応する。指示として聞き取れなかった言葉は字幕に出すだけで、聞き返さない。

走る位置は車線の線をなぞるだけでなく、少し左右に揺らぎ、指示で寄せられる。前にコーンなどがあれば、通れる位置を探してよけて通り（よけられないときだけ止まる）、通り過ぎたら車線に戻る。

道路から外れると（「今すぐ右」などで草地へ出たときも）、指示された向きへ自由に走る。このあいだは「右」「左」でその場で 90°、「ちょっと右」で 20° 向きを変え、「Uターン」で反対を向く。障害物があれば向きを少し変えてよけ、よけられなければ止まる。道路の上で道路の向きに乗るか、「道に戻って」で道路に着くと、また道路に沿って走る。

### 共通

| キー | ゲームパッド | 操作 |
|---|---|---|
| `C` | Y | カメラ切替（三人称 近／遠・運転席・助手席・車内カメラ） |
| `N` | BACK | マップ切替（小さな街／教習所コース） |
| `P` | - | 車の切替（普通車 108km/h／軽自動車 86km/h／スポーツカー 198km/h） |
| `O` | | みんなで走る（オンライン。部屋コードか招待リンクで参加） |
| `R` | START | スタート地点に戻る |
| `M` | | サウンド・アッティーの声 ON/OFF |
| `H` | | 操作説明の表示切替 |

### スマホ・タブレット

タッチ操作の画面が出る（パソコンでも画面に触れるか `?touch` を付けると出る）。

- 左半分を左右になぞる: ハンドル（指を置いた場所が中心）
- ☰ メニューの「ハンドル: 傾ける」にすると、スマホをハンドルのように傾けて曲がる（切り替えた時の持ち方がまっすぐ。左半分をタップすると今の持ち方をまっすぐに合わせ直す。iPhone では動きセンサーの許可を求められる）
- 右下のボタン: アクセル／ブレーキ（止まってから押し続けると後退）
- 上のボタン: カメラ切替・リセット。☰ メニューからモード切替・みんなで走る・マップ／車の切替・サウンドなど
- ホーム画面に追加すると、アドレスバーなしの全画面で遊べる（iPhone は Safari の共有ボタン →「ホーム画面に追加」。Android はメニューの「全画面で遊ぶ」でも可）。ホーム画面から開いたときは Safari と保存場所が別なので、顔写真や名前はもう一度設定する

URL に `?map=1` を付けると教習所コース、`?assist` を付けると指示モードから始まる。`?car=sport`（`standard`／`kei`／`sport`）で開始時の車を選べる。`?room=ABCD` は招待リンクで、開くと参加画面が出る。`?debug` を付けると開発者ツールから `window.__game` で状態を触れる。

## 開発

Node.js 22 以降。

```sh
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm test           # 単体テスト（Vitest）
npm run build      # 型チェック + 本番ビルド（dist/）
```

### 顔写真の立体化

目と口の中は MediaPipe の三角形では穴になっているので、縁の特徴点でふさいで写真の目と口を貼る。顔写真を決定したときだけ、MediaPipe の Face Landmarker（`@mediapipe/tasks-vision`）を読み込んで顔の特徴点 478 点を読み取り、頭の球に沿わせた立体（`src/face/shape.ts`）にする。読み取り用の WASM（約 10MB、ビルド時に `node_modules` から `dist/mediapipe/` へコピー）とモデル（`public/mediapipe/face_landmarker.task`、約 4MB）はこのサイトから配り、外部には通信しない。顔写真を使わなければ読み込まれない。

### オンライン（マルチプレイ）

クライアント権威方式: 各プレイヤーが自分の車を計算して 20 回/秒で位置を送り、サーバー（Cloudflare Workers + Durable Objects）は部屋ごとに中継するだけ。他の人の車は 0.1 秒前の位置を補間して表示し、自分の物理ワールドには動かない車体として置く（ぶつかると自分の車だけが押し返される）。

無料枠を守るための制限:

- 接続できるのはゲームのページ（`https://shuheikomatsuki.github.io`）と手元の `localhost` からだけ。ほかのサイトからの接続は断る。
- 日本国内（Cloudflare が IP から判定）からの接続だけ受け付ける。対象は `server/wrangler.jsonc` の `vars` で変えられる（`"*"` で制限なし）。
- 5 分間車が動いていない人は部屋から外す。つないだまま 15 秒以上参加しない接続も切る。
- タブが裏に回っている間は位置を送らない。
- 最後の 1 人が抜けた部屋は、保存していた値（マップ）を消す。

手元で試すとき（`npm run server:dev` は国の制限を外して起動する）:

```sh
npm run server:dev                      # http://127.0.0.1:8787 でサーバーを起動
npm run dev                             # 別のターミナルで
# http://localhost:5173/?server=http://127.0.0.1:8787 を2つのウィンドウで開き、O キーで同じ部屋コードに参加
```

公開の設定（初回のみ）:

1. Cloudflare のダッシュボードで「Workers & Pages」を一度開き、`workers.dev` のサブドメインが作られていることを確認する。
2. 右上のアイコン → My Profile → API Tokens → Create Token → テンプレート「Edit Cloudflare Workers」でトークンを作る。
3. アカウント ID を控える（ダッシュボードのアカウントのホーム、または Workers & Pages の画面の右側に表示）。
4. GitHub のリポジトリ → Settings → Secrets and variables → Actions の **Secrets** に `CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` を登録する。
5. main の CI（Actions → 最新の main の実行 → Re-run all jobs）を実行すると `deploy-server` ジョブがサーバーを公開し、ログに `https://car-game-server.<サブドメイン>.workers.dev` が出る。
6. 同じ画面の **Variables** に `SERVER_URL` としてその URL を登録し、もう一度 CI を実行すると、ゲーム側にサーバーの URL が組み込まれる。

### 構成

| ディレクトリ | 役割 |
|---|---|
| `server/` | マルチプレイの中継サーバー（Cloudflare Workers + Durable Objects） |
| `src/net/` | 通信内容の定義、WebSocket 接続、受信した車の補間 |
| `src/core/` | 固定タイムステップのゲームループ、キーボード・ゲームパッド入力 |
| `src/face/` | 顔写真の切り抜き・テクスチャ作成・ブラウザ内保存 |
| `src/game/` | マップ1つ分（物理ワールド・車・描画物）の生成と破棄、他のプレイヤーの車 |
| `src/audio/` | Web Audio API で合成する効果音（エンジン・スキール・衝突） |
| `src/ai/` | キャラクター運転: 指示の解析、経路計画、運転制御、性格（苦手さ）、セリフ |
| `src/voice/` | 音声認識（指示の聞き取り）と音声合成（セリフの読み上げ） |
| `src/sim/` | 車両モデル（`vehicle.ts`、描画非依存）、Rapier 物理ワールド、車 |
| `src/map/` | タイルマップ定義（`maps.ts`）と解析、障害物配置 |
| `src/render/` | Three.js のシーン、マップ・車・標識のメッシュ、カメラ |
| `src/ui/` | HUD（速度・ギア・操作説明・通知） |

- 車の挙動の調整は `src/sim/vehicle.ts` の `DEFAULT_VEHICLE_PARAMS`。
- キャラクターの苦手さは `src/ai/personality.ts`、セリフと名前は `src/ai/dialogue.ts`。
- マップは `src/map/maps.ts` の文字グリッドを書き換えるだけで変更・追加できる（凡例は `src/map/tilemap.ts`）。標識やカーブのガードレールもここで指定する。

### 公開

`main` ブランチへ push すると GitHub Actions がテスト・ビルドし、GitHub Pages に公開する。
初回のみ、リポジトリの Settings → Pages → Source を **GitHub Actions** に設定する。
