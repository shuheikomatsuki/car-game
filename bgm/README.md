# BGM

このフォルダに音声ファイル（mp3 / m4a / aac / ogg / opus / wav）を置くと、ビルド時に自動でゲームの BGM 一覧に入る。

- 曲名はファイル名から作る（拡張子と先頭の番号を除き、`_` は空白になる）。例: `01_峠の朝.mp3` → 「峠の朝」
- 一覧はファイル名の順（数字は数として比べる）。順番を決めたいときは先頭に `01_` `02_` … を付ける。
- 遊ぶ人は 設定 → BGM で「なし → 各曲 → シャッフル」を選べる（2曲以上でシャッフルが出る）。曲が1つもなければ設定に BGM は出ない。
- サイトは公開されるので、配布・公開してよいと許可されている曲（フリー素材など）だけを置く。
- ファイルは小さめに（1曲 3〜5MB 程度、mp3 128〜192kbps くらい）。
